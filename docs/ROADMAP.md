# Roadmap
1. First playable: window, local input, fixed-step movement, gravity, collision, robot/vehicle transformation, third-person camera and HUD.
2. Next large visible milestone: a local combat arena with aim reticle, hitscan or projectile weapon, visible impact feedback, destructible target health bars, pickups and a simple patrolling/chasing enemy. Use original placeholder assets and the existing gameplay contracts.
3. Movement polish: ramps, swept collision, camera smoothing, vehicle steering and improved transform animation.
4. Content pipeline: original meshes/materials, animation playback, local audio cues and data-driven map loading.
5. Local game loop: spawn/death/respawn, objectives, team rules and match UI.
6. Rendering modernization only after gameplay proves the interfaces useful.

Networking and proprietary online services are outside the scope of this project. The empty Online interface reserves no implementation commitment.
