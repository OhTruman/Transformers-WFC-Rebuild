# Death presentation: the original's audio and effects for Gameplay patch 2 (Systems, 2026-10-17)

Data: docs/handoff/deathfx/DeathFx.inc (copy to src/game/DeathFx.inc), generated by tools/systems/gen_death_fx.py from
AssetTools authored.db (read only). One row per death-blueprint entry (TnDeathType<Name> -> c.entry's short name), in the
blueprint's order: the entry's gib DSYS (UseCustomGibs ? its GibsBlueprint, None = no gibs : the blueprint default) as its
particle templates + offsets, whether it spawns RB_Gib chunks, its sound cue; skeletal gib / decals (the same UseCustom rule);
TnDeathModifierPlayEffect templates + socket + Delay max. Plus TnPawn.GibbedCameraShake and TnPlayerController.DeathSound.

## Hook (Gameplay owns the call sites; this is the data API)

```cpp
#include "game/DeathFx.inc"
// The row of a picked entry: blueprint = the corpse's death blueprint (SharedRobotDeaths / SharedCarDeaths / ...), entry = c.entry.
inline const DeathFxEntry* deathFxFor(const char* blueprint, const char* entry) {
    for (const DeathFxEntry& e : kDeathFx) if (!std::strcmp(e.blueprint, blueprint) && !std::strcmp(e.entry, entry)) return &e;
    return nullptr;   // unknown -> today's defaults
}
```

1. **World::gibCorpse** (Deactivate): with the row r: if r->nGibFx == 0 and !r->chunks, no default fx / chunks (Energy,
   Melee); else spawn r->gibFx[i] at c.pos + (x, y, z) UU (UE Z up -> our Y; DefaultGibs' +50 UU replaces today's 0.5 m for
   robots) and the 4 chunks only if r->chunks; the skeletal gib only if r->skeletalGibs and the blueprint's spawner has
   Templates (SharedCarDeaths / Tank / Jet spawners have none -> no skeletal gib for vehicles, as today); the scorch only if
   r->decals; r->gibCue if non-empty (campaign only).
2. **World::tickCorpses PlayEffect** (c.fxAt): spawn every r->play[i] at its socket (Head_FX / BoosterSocket_C / Chest_FX /
   TargetingSocket / VaporTrailSocket_R - today's head bone / +1.5 m / +1.0 m stand-ins for sockets the model lacks), with
   the one shared delay U(0, delayMax) the modifier already draws.
3. **Gibbed shake**: at gibCorpse, if the local view is within kGibbedCameraShake.distanceUU / 100 m of c.pos, start a shake
   with those values (the TnCameraShaker / CameraShake model the death camera's wiggle uses).
4. **Local death cue**: at the local player's death (where beginDeathCamera is called), play kLocalDeathCue 2D (UI
   category) once - Systems can add this call itself in Application's death path if Gameplay prefers (AbilityAudio has the
   cue player); say which.

Identity: presentation only (no sim state): SIMHASH unchanged; Off / Faithful frames change only on death frames of the
entries whose effects change (Energy, Poke, SingleShot, TractorBeam deaths; HeadShot / momentum if the pair played before).
Audio check: the local death cue counted from a paced run (lockstep + WFC_FRAMELIMIT=60, WFC_MUTE=1 still logs cue starts).
