# Online: where our PC rules deviate from the original (hand-over notes, 2026-10-23)

Each row puts our current rule beside the original rule.

**Sources:**
- **Original:** RE in this lane: ONLINE_PARTY_RE, ONLINE_PUBLIC_MATCH_RE, ONLINE_RULES_CHECK_RE, MP_INPUT_CONTRACT_RE §3, the
  game-lobby GRI bytecode (`TnGameReplicationInfoGameLobby`), MP_ESCALATION_RE §8.4, CAMPAIGN_FRONTEND_FLOW_RE.
- **Ours:** Rebuild `docs/handoff`:
  - ONLINE_LOBBY_FLOW_V2 (Frontend, 10-17), ONLINE_MATCHMAKING_DESIGN (Systems, 10-17);
  - ONLINE_MP_FLOWS (decisions D4–D16), ONLINE_MP_PHASE2_FLOWS, ONLINE_PHASE2_SPLIT.

**Labels:** C = the original rule is confirmed from script or data; H = inference. **LIVE** = the original rule lived in Xbox Live /
Demonware and has no counterpart without that platform.

**Why the original rules can't simply be copied:** the original was a Live title. It had Live parties, friends, invites, presence,
matchmaking queries and the NAT type. Our PC build is peer-to-peer lockstep, with an optional lobby service on a VPS. Most rows
below follow from that.

## 1. Deviations

## 2. Where we match (no deviation)
- Per-mode score, time, rounds and team-balancing defaults; countdowns 10 / 15 / 1.5 s; respawn 5 s and the 3 s spectate; the
  lobby status texts (except the singular "Finding `p more player", which is still open in ONLINE_RULES_CHECK_RE §3.3).
- After a match the whole game returns to the host's game lobby, with the party kept (P6).
- Joining someone else's game from a party disbands that party (the prompt is kept).
- Host-only settings and the playlist lock in public play.
